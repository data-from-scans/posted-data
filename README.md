# posted-data

Data files and figures that accompany posts I make on public forums and communities.

Every dataset lives in its own folder with a `README.md` recording where the numbers came
from, which year/vintage they are, and how the figure was rendered. Files are published
exactly as used in the post they belong to — no edits afterwards, so that what a reader
sees matches what was linked.

## Datasets

| Folder | What it is |
|---|---|
| `china-gdp-provincial-sum-vs-national/` | The 31 provincial-level GDP figures added up, against the national total, 2015–2024 (CSV + figure) |

## Sources and reuse

The underlying statistics belong to the statistical agencies that publish them (National
Bureau of Statistics of China in the dataset above). The compiled files here — the CSV as
put together, the figures as drawn — are licensed **CC BY 4.0**: reuse freely, credit the
compiler, and check the per-dataset README for the exact source and caveats.

## Notes

- These are fixed vintages. Chinese national accounts figures get revised (routine
  verification, and the fourth/fifth economic censuses), so the same year can carry two or
  three different official numbers. The notes say which one each column is.
- Corrections: if you find an error, open an issue and I will fix the file and say so in
  the post thread.
